# Сказки со звуками

Прототип для семейного теста: взрослый читает ребёнку сказку, телефон добавляет звуки — по касанию текста или сам, слушая чтение.
Распознавание речи работает только на устройстве (Vosk, модель vosk-model-small-ru-0.22, Apache-2.0); голос никуда не отправляется.

- Тексты: Ушинский, Толстой — общественное достояние (Викитека).
- Звуки: записи с Wikimedia Commons, авторы и лицензии — `audio/CREDITS.md`.
- Распознавание: [vosk-browser](https://github.com/ccoreilly/vosk-browser) (Apache-2.0), модель [Vosk](https://alphacephei.com/vosk/models) (Apache-2.0).

Подробности устройства — `README_PROTOTYPE.md`.
